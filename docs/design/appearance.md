# Feelime 外观方案

本文档定义键盘与设置页的统一视觉语言：新增任何可见元素（按键、工具、
浮层、卡片、状态）都必须套用这套体系，避免局部好看但破坏整体风格。
色彩 token 的权威取值表见 [keyboard.md §1.1](keyboard.md)；本文讲规则。

## 1. 设计基调

- **中性灰底 + 单一强调色**：整套界面只一个强调色 `--accent`（绿
  `#23c890`），只表达「当前/选中/可确认」一类语义；其余全部用灰阶层次。
  不为单个功能引入第二强调色。
- **扁平、轻装饰**：键面无渐变、无重投影；层次靠明度差表达
  （bg → key/special → pressed → panel → pill）。
- **圆角键帽**：按键 5px（`--radius-key`）、卡片/浮层 10px
  （`--radius-card`）、工具钮正圆；同一类元素全仓共用同一圆角，不出现
  第三种圆角。
- **密集但透气**：间距节奏 4/5px（键距、行距、浮层内边距的倍数），
  不为单个元素发明新间距。

## 2. 表面与文字层次

| 层次 | token（dark / light） | 用于 |
| --- | --- | --- |
| 底 | `--bg` `#202020` / `#e2e3e8` | 键盘区背景 |
| 普通键面 | `--key` `#5f5f5f` / `#fcfcfc` | 字母键 |
| 功能键面 | `--special` `#414141` / `#b7bbc4` | shift/退格/123 等功能键 |
| 按压 | `--pressed` `#6e6e6e` / `#eceef2` | 任何可点元素的按住反馈 |
| 卡片 | `--panel` `#2a2a2a` / `#f4f5f7` | 菜单、面板、浮层 |
| 药丸 | `--pill` `#3d3d3d` / `#ffffff` | 首候选 pill、选中 chip |

- 主文字 `--text`，次要文字 `--muted`。**次要文字必须过 WCAG AA
  （≥4.5:1）**：浅色 `--muted` 取 `#5c616b`（--key 6.1:1 / --panel
  5.7:1 / --bg 4.9:1）。`--special` 面上放 `--text`，不放 muted。
- 强调**填充**（`--accent` 当底）与强调**文字**分开：绿底上的字用
  `--accent-ink`，普通底上的强调字用 `--accent-text`。禁止拿 `--accent`
  直接当小字色（浅底上发虚、深底上刺眼）。

## 3. 亮暗双主题

- 主题机制（keyboard.md §13）：默认 `:root` 深色；`html.theme-light` /
  `html.theme-dark` 由原生 hello 驱动；两者都缺时 `prefers-color-scheme`
  兜底。
- **每个 token 必须三处成对定义**：`:root`（深色值）、
  `html.theme-light`、`@media (prefers-color-scheme: light)` 的兜底块。
  只改一处就是主题回归。
- 新颜色先问「token 表里有没有近义」；没有就**加 token**，不写散色。
  少数硬编码语义色是像素门禁依赖，不许动、也不许新加：修饰键锁定底
  `#103a24`、`--scrim`。（语音浮层的录音/错误色已并入 accent 调色板
  token：`--recording`/`--danger`，无红色像素门禁。）

## 4. 状态表达

| 状态 | 表达 |
| --- | --- |
| 按住 | 面色变 `--pressed`（不缩放、不变色相） |
| 选中/当前/武装 | `--accent`：填充位（首候选 pill 文字、当前模式行）或 `--mod-active-bg`（修饰键锁定底） |
| 禁用 | 面色不变、文字/图标降为 `--muted` 且不可点 |
| 危险/删除 | `--danger`（删除按钮、错误文案） |
| 录音 | `--recording`（麦克风图标与浮层），与 `--danger` 分开 |
| 次要提示 | `--muted`（副标、角标 alt、占位文字） |

- 触摸反馈必须存在：所有可点元素走 bindTouch 的 active-touch 链路
  （WebView 里 `:active` 不可靠）。
- 粘滞键「武装」与「按住」必须可区分：武装=绿（accent 系），按住=灰
  （`--pressed`）。

## 5. 图标与字排

- 图标一律单色 SVG path（`currentColor`），线性风格、笔画粗细一致；
  新图标从现有图标的网格与笔画粗细出发，不混用 emoji。
- 字排全部走系统字体栈；主键字母 22px w400、候选 17px（三档）、preedit 13px 基值
  （三档缩放）、副字/角标 9–11px；字号随键高缩放（keyboard.md §1.2），永不溢出键面。
- 全角标点等字形墨迹偏移的字符做光学居中修正（keyboard.md §1.1），
  验收看截图墨迹，不看 flex 盒子。

## 6. 浮层与卡片语言

- 浮层 = `--panel` 底 + `--radius-card` 圆角 + `--line` 细边框 + 轻投影；
  遮罩只用 `--scrim`。
- 关闭/收起按钮：条带动作（不是键）用无框样式；浮卡角标用 28px 正圆
  （`--special` 底 + 边框 + 投影），absolute 在卡片右上角、不占内容格。
- 浮层几何遵守 keyboard.md §0：锚定触发键、不遮触发键、不出窗口。
- 浮卡（常用语编辑卡、高度卡）浮动在键盘上方的原生扩展带里，不挤压
  键盘行高；按钮共用同一套卡片按钮样式（圆角对齐键帽 5px，主按钮
  accent 填充、次按钮描边）。

## 7. 新增可见元素检查单

动手前逐项过一遍（任何一条不满足就先补设计）：

1. 颜色全部来自 token？亮/暗两套值都补齐（三处）了？
2. 文字/图标在两种主题下都过对比度？（贴实际色值算，不靠感觉）
3. 圆角、间距、字号落在现有体系内（5px/10px 圆角，4/5px 间距倍数）？
4. 有按压反馈（active-touch）？有禁用态？
5. 图标是同风格单色 SVG？文字与图标不同时出现造成拥挤？
6. 浮层锚定不遮触发键、不出 IME 窗口（keyboard.md §0）？
7. 深浅两主题、横竖两方向的截图各一份验收；DOM 断言不能代替视觉核对。
8. 不动像素门禁依赖的硬编码色；若必须加，先补门禁再合码。

### 7.1 T9 九宫格键面（t9 模式，keyboard.md §2.7）

- 左列条格（`.t9-side-cell`）= `--special` 表面 + `--text`，声母前缀
  （`.t9-syl-pre`）用 `--key-subtext` 置灰；符号键沿用 kb-special 灰。
- 角标（`.t9-sup`：字母组数字、空格的 0）= 10px `--key-subtext`，
  与 qwerty 键角标同语言；主字形 `.t9-group` 沿用 `.kb-main` 字号体系。
- 浮层（T9 长按三行 `.t9-grid3`，含字母/符号·数字/大写）沿用
  `#keyPopup`/`.kp-item` 卡片语言；选中格 `--accent` 填充。
- 深浅主题验收截图：`t9.md` §2 定稿时的 preview 页 + 设备截图存档。

## 8. 完整设置页

设置页（`assets/settings/`）与键盘同源 token、同主题机制；卡片圆角、
按钮、分组标题遵守同一套规则；`--accent-text`/`--input-placeholder`
等文字 token 在浅色主题下的取值以 keyboard.md §1.1 为准。
