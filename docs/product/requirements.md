# Feelime 需求清单（整合版）

本文是产品最终需求的整合视图：输入、界面、语音、模型、更新、渠道与
质量门槛。历史迭代中的临时口径已并入最终语义；「实现状态」不在本文
范围内——代码与验证记录才是事实来源。设计语义见
[design/keyboard.md](../design/keyboard.md)，验收方法见
[testing/verification.md](../testing/verification.md)。

## 6. 已知边界（声明不修 / 外部依赖）

- **ColorOS 焦点清除**：EditText 收到 Esc 键后 view 级焦点被清，键事件
  通道暂时失效，重聚焦恢复（keyboard.md §10.7）。
- **远程桌面 Win+字母**：客户端事件模型无法表达按住 Win，属第三方限制；
  其余组合经物理事件序列可用（keyboard.md §11）。
- **密码框被 OEM 安全键盘接管**：IME 收不到 EditorInfo，敏感判定由
  单测矩阵覆盖（keyboard.md §10.7）。
- **xterm.js 宿主 InputConnection 不可探测**：行为探针无法与真实编辑器
  区分，终端类按包名路由到键事件通道（keyboard.md §10.2）。
- **删词复活**：librime 删除标记在词再次上屏时复活（引擎同语义）。
- **双拼输入码**：按实际键序匹配（keyboard.md §7.4）。
- **Shift 锁定语义**：长按锁定（默认 350ms，可在设置调整），不提供
  双击锁定——两者手势冲突，长按已与弹层/锁定交互统一。
- 商店交付、正式签名、公开隐私政策页依赖外部账号/密钥接入；本地实现
  与测试不代替商店验收。
