# 术语表（沟通词汇）

项目沟通、issue 反馈、文档里反复出现的词汇在这里对齐口径，避免理解偏差。
每条给出**代码锚点**（元素 id / 文件），以代码实际为准；口语里容易混用的
词在「注意」里点破。新词汇进文档前先来这里登记一行政定名。

## 键盘顶部一行

| 词汇 | 代码锚点 | 定义 |
| --- | --- | --- |
| 候选条 | `#candidateBar`（index.html） | 键盘最顶部的整行。由左工具组、候选词区、右工具组、收起键拼成。口语里的「工具栏那一行」指它。 |
| 工具栏 | `toolbarLeft` / `toolbarRight`（keyboard.js） | 候选条上的快捷按钮组（左右两组，各上限 4 颗，可在「编辑工具栏」里增删排序）。它是候选条的**组成部分**，不是另一个东西。 |
| 候选词区 | `#candidates` | 候选条中间的横向滚动区，显示候选词 / 联想词 / 手写候选 / T9 符号行。编辑态空置时有「候选词区」ghost 占位。 |
| F 按钮 | `#setupButton` | 候选条最左的设置入口按钮（图标 F.），点开「快捷设置」面板。 |
| 收起键 | `#hide` | 候选条最右的 ⌄ 按钮，收起整个键盘。 |
| ×（清空） | `#composeClear` | 让位态行内的清空按钮：清候选/联想/笔迹并恢复工具栏。 |

## 面板与设置

| 词汇 | 代码锚点 | 定义 |
| --- | --- | --- |
| 快捷设置 | `#settingsPanel`（keyboard.js tiles） | 点 F 按钮在键盘内弹出的面板（主题、长按时长、编辑工具栏、完整设置等方块）。 |
| 完整设置 | `assets/settings/`（独立 WebView 页） | 完整的设置页（输入、外观、词库、关于等卡片），从快捷设置「完整设置」进入，也可从系统输入法设置进入。用户口语里的「设置页」多指它。 |
| 编辑工具栏 | `enterToolbarEdit()` / `body.toolbar-edit` | 增删排序工具按钮的编辑态：长按 mic 或快捷设置「编辑工具栏」进入，栏上按钮带 ×，下方是仓库。 |
| 仓库（pool） | `#toolbarEditorGrid` | 编辑工具栏时下方待添加的工具格子区。 |

## 输入状态

| 词汇 | 代码锚点 | 定义 |
| --- | --- | --- |
| 组合（composing） | `composing` / `#preeditLine` | 拼音等编码的中间态：按了 ni 但还没选字。组合行显示编码，候选词区出候选。 |
| 上屏（commit） | `Native.commitText` 等 | 组合确认、文本最终进入编辑框。 |
| 联想（association） | `assocWords` / `onAssoc` | 上屏后候选词区给出高频接续词，点击可连续上屏。设置「中文联想」开关控制。 |
| 让位（yield） | `setToolbarYield()` | 候选条被手写候选 / 联想 / T9 符号行等互斥视图占用时，工具按钮整组隐藏、行内只留 ×。 |
| 退格 | `[data-role=backspace]` | 删除键。统一出口 `backspaceAction()`（联想让位态开关开启时=清联想）。 |
| 模式 | `selectMode()` | 拼音 / 双拼（小鹤等）/ T9 / 笔画 / 手写 / 英文 / 终端等键盘形态。 |

## 引擎与数据

| 词汇 | 代码锚点 | 定义 |
| --- | --- | --- |
| 方案（rime schema） | `files/engine-data/**/rime/` | librime 输入方案（luna_pinyin、feelime_flypy、万象拼音等），决定编码规则与候选。「换装」=安装并切换第三方方案。 |
| 直发 | `Native.commitText` | 绕过引擎直接把字符写进编辑框（符号面板、粘贴等走这条路）。 |
| 按键通道 | `Native.key` | 字符进引擎参与组合的通道（字母键等）。万象 / 键引导类功能依赖它。 |
| built-in 副本 | `files/keyboard/` | 设备上键盘 JS 的内置版本；重装 APK 不一定刷新，验证前先核设备实际版本号。 |
